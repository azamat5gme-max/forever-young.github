FOREVER YOUNG — SITE CODE

1. Extract this ZIP into a folder.
2. Open index.html in your browser, or open the folder in VS Code and use Live Server.
3. Keep style.css, script.js, and the assets folder beside index.html.

All three sample photos and the display font are included. No installation or build step is required.

YOUR OWN PHOTOS
Replace assets/crew.jpg, assets/adventure.jpg, and assets/city.jpg with your own pictures. Keep these filenames, or change the three img src values in index.html. Update the descriptions, SAMPLE PHOTO labels, note below the photo wall, photo credits, and the sample-photo suffix in script.js when replacing the sample images.

PUBLISHING
To let other people open the site, upload the files to a static web host such as GitHub Pages. A website address is configured in your hosting and domain settings; editing HTML does not change its address.

The displayed site name is Forever Young. This portable copy leaves out the previous hosted address from social metadata so it is ready for your own hosting.
